🏀 Basketball

Le basketball oppose deux équipes de cinq joueurs. L'objectif est d'envoyer le ballon dans le panier adverse. Discipline olympique depuis 1936.

Système de points

  • Panier classique : 2 points
  • Tir à 3 points : 3 points
  • Lancer franc : 1 point

Les postes

  • Meneur : organise le jeu
  • Arrière : spécialiste du tir
  • Ailier : joueur polyvalent
  • Pivot : protège le panier

Épreuves olympiques

  • Tournoi masculin
  • Tournoi féminin
  • Basketball 3x3
